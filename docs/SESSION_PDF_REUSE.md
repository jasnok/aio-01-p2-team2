# 분석 PDF의 세션 내 재사용

결과 화면이 다시 실행될 때 같은 PDF를 매번 생성하던 경로를 개선했다. 사용자 세션에 결과 내용의 SHA-256과 PDF 바이트 한 개만 보관한다. 내용이 달라지면 기존 바이트를 제거하고 재생성한다. 같은 결과는 최초 PDF의 생성 시각과 내용을 유지한다.

실패한 PDF는 저장하지 않으며 다음 화면 실행에서 다시 생성할 수 있다. 새 분석 제출, 새 분석 시작, 분야 전환, 로그인·로그아웃·인증 만료 등 개인 상태 초기화에서 캐시를 제거한다. 공유 전역 캐시·영구 파일 저장은 추가하지 않았다. 총 바이트 상한이나 자동 TTL 삭제 기능은 추가하지 않았고 세션별 마지막 PDF 하나로 항목 수만 제한한다.

`frontend/tests/test_pdf_session_reuse.py`는 같은 결과의 반복 생성 방지, 같은 요청 ID의 내용 변경 시 재생성, 실패 후 재시도, 별도 세션의 생성 격리 및 인증/새 분석 초기화를 검사한다. 기존 실제 PDF 한글·인용·본문 회귀 검증도 유지한다. 생성 호출 횟수 감소를 확인했으며 응답 속도 개선 비율을 측정했다고 주장하지 않는다.
