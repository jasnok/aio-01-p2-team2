# 용어 대화의 응답 ID와 저장 상태

프런트엔드의 용어 대화 응답은 conversation_id를 엄격한 양의 정수 또는 null로 검증한다. 문자열·불리언·실수·0·음수는 대화 상태에 반영하기 전에 CONTRACT_MISMATCH로 차단한다. saved=True는 member 저장 위치와 유효한 대화 ID가 함께 있어야 승인한다.

새 대화의 null ID, 이어지는 대화의 양의 정수 ID, 회원 저장 완료, 게스트 임시 보관의 정상 응답은 유지한다. 다른 화면의 식별자 계약은 변경하지 않았다.

클라이언트 및 실제 Streamlit AppTest를 포함한 새 테스트 16개는 비정상 응답 차단과 기존 메시지·대화 ID·입력값 보존을 확인한다. 기존 저장·용어 대화 테스트까지 관련 테스트 37개가 통과했다. API 요청의 서버 처리 여부나 자동 재시도에 관한 보장은 추가하지 않는다.
