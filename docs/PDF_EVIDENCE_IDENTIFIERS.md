# PDF 인용과 자료 본문 연결

## 문제와 변경

분석 결과 PDF에는 주장별 인용의 `evidence_id`와 인용문이 있었지만, 관련 법령·유사 판례·소비자원 상담사례의 본문에는 ID가 표시되지 않았다. 제목이 같은 자료가 여러 개이면 문서만으로 인용이 어느 본문에 해당하는지 찾기 어려웠다.

각 자료의 제목 바로 아래에 응답에 포함된 `evidence_id`를 표시한다. 문서의 인용 ID와 본문 ID를 대조할 수 있다. 과거 저장 결과처럼 ID가 없는 자료에는 임의 ID를 만들지 않는다. 출처 URL과 내부 메타데이터는 기존대로 출력하지 않는다.

## 검증 범위

`frontend/tests/test_pdf_export.py`에서 실제 PDF 바이트를 생성하고 pypdf로 텍스트를 추출한다.

- 세 자료 종류에 같은 제목을 사용해도 각 인용과 본문에 원래 ID가 유지된다.
- ID가 없는 기존 자료의 본문도 출력된다.
- 한글, `<`, `>`, `&`가 포함된 ID와 인용문이 ReportLab 마크업으로 해석되지 않고 보존된다.
- 기존 다중 페이지 한글 본문, 검색 점수, 생성 실패 안내, 출처 URL 비노출 테스트를 유지한다.

이 변경은 인용의 식별 가능성을 개선한다. 인용 내용의 법률적 타당성이나 모델 답변의 정확도를 새로 평가한 것은 아니다. 텍스트 추출 검증은 시각적 페이지 배치 검증과 구분한다. 추가 모델 호출이나 영구 사용자 파일 저장은 발생하지 않는다.
