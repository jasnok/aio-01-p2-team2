# 인증 갱신 계약과 역할 변경

실제 `/api/auth/me`의 `user`와 `authenticated`를 전용 모델로 검증합니다. authenticated는 정확한 bool이어야 하며 누락·문자열·정수는 인증을 확인한 것으로 취급하지 않습니다. 비정상 응답과 게스트 또는 인증되지 않은 응답은 기존 만료 처리로 개인 분석·용어 대화·이력 상태를 초기화합니다.

사용자 ID뿐 아니라 역할도 비교합니다. 같은 ID의 USER/ADMIN 역할이 바뀌면 이전 개인 화면 상태를 초기화한 뒤 새 사용자 정보를 반영합니다. 서버의 권한 검사를 대신하는 기능은 아니며 서버 정책·세션 저장소는 변경하지 않습니다. 정상 동일 사용자 갱신은 화면 상태를 보존하고 기존 60초 확인 주기를 유지합니다.

401은 세션을 만료시키지만 일시적 503이나 연결 실패는 안내 후 기존 세션을 보존합니다. 성공으로 확인 시간을 갱신하지 않으므로 다음 실행에서 다시 확인할 수 있습니다. 로그인 응답이 객체가 아닌 경우도 원시 AttributeError 대신 안전한 계약 오류로 처리하며 기존 사용자 상태를 변경하기 전에 검증합니다.

합성 UI 테스트는 비정상 authenticated·게스트·인증되지 않은 응답, 동일 사용자와 역할 변경, 401/503의 상태 차이, 비객체 로그인 응답을 검증합니다. 사람 개인정보·실제 로그인 토큰이나 모델 요청은 테스트에 사용하지 않습니다.

저장 흐름 회귀 포함 대상 테스트 30개와 실제 Redis·PostgreSQL 통합 포함 전체 로컬 테스트 561개 통과·4개 외부 테스트 제외를 확인했습니다. frontend Docker 빌드·재생성 후 health HTTP 200, 측정 요약 일치 검사와 diff 공백 검사도 통과했습니다.
