# 대화 오류 후 화면 연속성

용어 대화와 추가 정보 분석의 제출 처리를 각각 작은 함수로 분리했다. 입력 검증 실패나 요청 오류는 제출 처리만 종료하며, 화면은 이전 대화와 새 분석 시작 버튼을 계속 렌더링한다. 유효하지 않은 입력은 서버로 보내지 않는다.

기존 성공 경로의 메시지 추가, 저장된 대화 ID, 입력 초기화, rerun 및 새 분석 동작은 유지한다. 오류 후 자동 재시도는 추가하지 않았다.

실제 Streamlit AppTest 6개로 짧은 용어 질문·공백 질문·용어 요청 오류·짧은 추가 정보·합산 길이 초과·분석 오류를 확인했다. 이전 답변 표시, 입력값과 대화 상태 유지, 요청 횟수, 새 분석 버튼 및 초기화 동작을 검증했다. 기존 대화·보완 입력 테스트를 포함한 관련 테스트 18개가 통과했다.
