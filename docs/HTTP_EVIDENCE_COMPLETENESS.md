# HTTP 측정 원본의 완전성 검증

기존 요약 생성기는 HTTP 결과의 각 행을 검증했지만 세 분야가 모두 포함되었는지 확인하지 않았다. 분야 하나가 빠지거나 결과가 비어 있어도 기존 SDK·키워드 행으로 요약을 생성할 수 있었다. 요청 수의 `false` 또는 `0.0`도 숫자 0 비교를 통과했다.

HTTP 결과는 주거·노동·소비자 세 분야가 정확히 있어야 한다. 인증·모델 요청 수는 정확한 정수 0이어야 한다. 준비 수는 음수가 아닌 정수, 표본·동등 비교 수는 양의 정수로 확인한 뒤 기존 표본/중앙값/동등성 검증을 수행한다.

`frontend/tests/test_portfolio_evidence.py`에서 누락 분야·빈 결과·불리언 요청 수·실수 요청 수의 잘못된 통과를 수정 전 4개 실패로 재현했다. 준비/표본/비교 수의 잘못된 자료형도 회귀 검사한다. 정상 측정 원본과 기존 생성 JSON은 변경하지 않으며 새 측정·API 요청을 수행하지 않았다.
