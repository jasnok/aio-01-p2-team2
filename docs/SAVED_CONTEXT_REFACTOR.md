# 저장 대화 문맥 조회 단순화

## 문제와 변경

용어 대화에 다른 분야의 저장 대화 ID를 넣으면 가져오지 않은 예외 클래스를 사용하여
NameError가 발생했다. SavedConversationNotFoundError를 명시적으로 가져와 라우터가
의도된 404 NOT_FOUND 응답을 반환하도록 수정했다. 잘못된 대화는 모델을 호출하지 않는다.

정상 용어 대화는 restore로 소유자와 분야를 확인한 뒤 일반 문맥 함수에서 다시 restore를
호출했다. 이미 검증된 메시지로 문맥을 만드는 순수 함수를 분리하여 조회를 한 번만 한다.
일반 분석과 용어 대화가 같은 선택·문자 제한 로직을 사용한다.

## 검증

- 정상 용어 대화의 저장소 restore 호출 수: 수정 전 2회, 수정 후 1회.
- 최초 사용자 질문과 최근 3개 메시지 선택, 중복 제거, 문자 제한 유지.
- 게스트는 저장소 조회 전에 거부하고 다른 회원의 대화는 기존 저장소 검증으로 거부.
- 다른 분야 및 분야 누락은 SavedConversationNotFoundError.
- HTTP 테스트에서 다른 분야의 대화가 404이며 모델을 호출하지 않는지 검증.

호출 수는 합성 저장소로 측정했다. 실제 DB의 전체 응답 시간 개선률이나 모델 생성 시간
개선으로 해석하지 않는다. 소유자 검증은 기존 저장소 restore의 책임을 유지한다.
