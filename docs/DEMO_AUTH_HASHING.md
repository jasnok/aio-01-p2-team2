# 운영·데모 인증의 공통 비밀번호 계산

`mock_store`의 중복 scrypt 구현을 제거하고 `password_service` 함수를 가져온다. 기존 import 경로와 해시 문자열 형식은 유지한다. 데모 로그인·회원가입도 `asyncio.to_thread`로 계산하여 이벤트 루프를 점유하지 않는다.

회원가입은 계산 전 중복 이메일을 확인하고, 계산 대기 이후 저장 직전에 다시 확인한다. 두 동시 요청이 처음 검사에 함께 통과해도 하나만 저장하고 나머지는 기존 HTTP 409를 반환한다. 최종 검사부터 저장까지 await가 없다. 이는 한 프로세스의 기존 메모리 데모 저장소 범위이며 다중 프로세스 영속성 보장을 추가하지 않는다.

새 테스트는 데모 인증의 스레드 실행·이벤트 루프 진행, 동시 가입의 이메일 유일성, 이전 해시와 한글 비밀번호 호환성을 검증한다. 커뮤니티 비밀번호 경로는 동기 FastAPI 라우트이므로 기존 실행 방식을 유지한다. 기본 executor와 요청 취소의 한계는 이전 인증 개선과 동일하며 속도 향상 수치는 측정하지 않았다.
