# Team Rules

## Branches

- `main`: 발표 가능한 버전
- `develop`: 통합 버전
- `feature/frontend`: 상옥
- `feature/backend-agent`: 다혁
- `feature/mcp`: 병훈
- `feature/rag-db`: 지혜

## Shared contracts

`backend/app/schemas`, `legal_mcp/schemas`, `docs/api-contract.md`를 변경하기 전에 팀에 공유한다.

## Secrets

`.env`, API Key, DB 비밀번호, 개인정보를 commit하지 않는다.
