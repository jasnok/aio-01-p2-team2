# 검색 임베딩 클라이언트 재사용

## 변경 이유

검색 질의 캐시는 동일 질의를 합치지만, 서로 다른 질의의 캐시 미스는 각각 OpenAI SDK 클라이언트를 생성했습니다. 생성 비용과 연결 재사용 기회를 줄이고, 생성한 클라이언트를 서버 종료 시 정리합니다. 데이터 수집용 임베더는 이번 변경 범위에 포함하지 않습니다.

## 동작과 수명주기

- 동일 모델·차원·API 키 설정의 검색 질의는 하나의 클라이언트를 재사용합니다. 생성만 동기화하고 API 요청은 잠금 밖에서 실행하므로 서로 다른 질의를 직렬화하지 않습니다.
- 설정이 바뀌면 새 클라이언트를 생성합니다. 이전 클라이언트는 진행 중인 요청이 모두 반환한 뒤 닫습니다. 평상시 하나를 유지하며, 설정 변경 중에는 진행 중인 요청이 사용하는 이전 클라이언트만 추가로 유지합니다.
- 캐시는 모델·차원·API 키 해시로 격리합니다. API 키 원문을 캐시 키·측정 결과에 저장하지 않습니다. 요청 실패는 캐시하지 않으며 공유 클라이언트는 다음 요청에서 재사용합니다.
- HTTP 서버 종료 시 새 클라이언트 획득을 막고 진행 중인 임베딩 호출이 끝나기를 기다린 뒤 정리합니다. 반복 종료 호출은 안전하며, 정리 실패가 발생해도 나머지 클라이언트의 정리를 시도합니다.
- MCP의 stateless 요청 수명주기와 HTTP 서버 수명주기는 다릅니다. `create_app()`은 기존 HTTP 세션 관리자의 수명주기를 감싸 서버 종료에 정리를 연결합니다. 취소 중에도 정리 작업을 보호합니다.
- API timeout 20초·SDK 재시도 1회, 질의 캐시 TTL 300초·최대 128개, 도구 계약 및 검색 결과는 유지합니다. 프로세스 간 클라이언트 공유나 API 요청 수 감소를 주장하지 않습니다.

## 측정

```powershell
.\.venv\Scripts\python.exe scripts/benchmark_embedding_clients.py --output output/portfolio/embedding-client-acquisition.json
```

실제 SDK 생성/획득만 측정했습니다. 명시적인 가짜 키를 사용하고 API 요청은 보내지 않습니다. 각 방식 준비 5회 후 15회 측정하며 클라이언트 종료 시간은 제외합니다.

| 로컬 Windows Python 3.12.7 | 중앙값 |
| --- | ---: |
| 질의마다 새 클라이언트 생성 | 383.5494ms |
| 기존 클라이언트 획득 | 0.0019ms |

원시 표본은 [측정 결과](../output/portfolio/embedding-client-acquisition.json)에 있습니다. 네트워크·모델·DB·검색 전체 지연은 이 측정에 포함하지 않습니다. 전체 사용자 응답 속도 개선률로 환산할 수 없습니다.

## 검증 범위

회귀 테스트는 서로 다른 질의 재사용, 설정 격리, 동시 생성, 요청 비직렬화, 이전 요청 중 설정 교체, 종료 대기, 생성/API/정리 실패 이후 복구, HTTP 서버 정상·오류·취소 종료를 검증합니다. MCP SDK의 세션 관리자는 인스턴스당 한 번만 시작할 수 있으므로 각 서버 테스트는 독립 인스턴스를 사용합니다.

실제 OpenAI 임베딩 호출의 품질이나 응답 속도는 이 테스트로 검증하지 않습니다. 실제 MCP HTTP 연결과 도구 목록 확인은 유료 모델 호출 없이 별도로 수행합니다.

로컬 Redis·PostgreSQL 통합 검증을 포함한 전체 테스트는 398개 통과·4개 외부 검증 건너뜀을 확인했습니다. Docker MCP 이미지 빌드·`pip check`·HTTP MCP 도구 6개 목록 조회도 성공했습니다. 서버 테스트에서 동일 MCP 세션 관리자를 재사용한 초기 실패는 독립 인스턴스로 수정하고 재검증했습니다.

Docker 내 별도 검증 프로세스에서는 실제 OpenAI SDK 클라이언트를 가짜 키로 생성하고 HTTP 앱의 정상 종료 후 `client.is_closed()`가 참임을 확인했습니다. API 요청은 없었습니다. 최초 확인 명령의 `is_closed` 메서드를 속성처럼 사용한 assertion 오류는 메서드 호출로 수정한 뒤 성공했습니다.
