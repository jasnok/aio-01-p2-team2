# 개인 포트폴리오 리팩토링 결과

검증일: 2026-10-01. 1차 작업 브랜치: `codex/portfolio-refactor-v1`. 한글 [이슈 #82](https://github.com/jasnok/aio-01-p2-team2/issues/82)·[PR #83](https://github.com/jasnok/aio-01-p2-team2/pull/83)로 기록했으며 CI 통과 후 `main`에 병합했습니다. 병합 커밋: `68dfe9c`.

## 구현한 개선

- 검색: 문서별 최고 점수 청크 보존, 법률 검색어 추출, 가중합·RRF 비교 옵션, 동일 질의 임베딩 캐시.
- 검색 SQL: 문서 본문 검사를 문서당 한 번 수행하도록 변경. 동일 결과를 유지하는지 기준선과 비교.
- 답변: 주장마다 근거 ID·원문 인용을 연결하고, 검색된 원문에 없는 인용은 대체 답변으로 처리. 화면과 PDF에 상태·인용 표시.
- 운영: Redis 실행 상태·SSE 이벤트 보관, 원자적 중복 요청 예약, 소유자 분리, 실행 시간 제한, 단계별 시간·생성 토큰 기록.
- 평가: 실제 API 시나리오, 검색 비교 30건, SQL 비교, 재시작 후 결과 복원 확인 스크립트와 결과 보관.

## 검증 결과와 해석

회귀 테스트 257개 통과, 기존 실서버 통합 테스트 4개 제외. 별도 실제 API 검증 4건은 주거·근로 LLM 답변 2건, 소비자 대체 답변 1건, 정보 부족 안내 1건입니다. 완료 결과 4건은 API 컨테이너 재생성 후에도 동일하게 조회됐습니다.

법령명·사건번호 조회 15건은 기존·개선 가중합·RRF 모두 상위 3개에서 대상 문서를 찾았습니다. 자연어 질문 15건의 관련성 정답은 아직 사람이 검토하지 않았습니다. `output/portfolio/relevance-review.json`에 검토 항목을 준비했습니다. 현재 결과만으로 검색 품질 향상이나 법률 정답률을 주장할 수 없습니다.

SQL 단일 비교에서 주택임대차보호법 8,286→75ms, 퇴직금 288→27ms, 환불 1,007→81ms였으며 문서·점수·청크가 같았습니다. 전체 서비스 지연 시간이나 p95 측정치는 아닙니다.

## 남은 품질 과제

소비자 질문의 인용 생성 안정성을 개선해야 합니다. 현재 원문 인용 검사는 인용문 존재를 확인하며 주장과 근거의 의미 일치·법적 타당성을 보장하지 않습니다. 자연어 관련성 수동 평가 후 검색 임계값을 보정하고, 분야별 자료를 확충해야 합니다. 중단된 작업의 자동 재개를 위한 영속 작업 큐는 구현하지 않았습니다.

## 실행과 촬영

`docker compose up --build -d` 실행 후 <http://localhost:8501>에 접속합니다. 현재 로컬 서비스는 실행 중입니다. 환경 설정·평가 재현 명령·약 3분 촬영 순서는 [로컬 실행 안내](DOCKER_LOCAL_SETUP.md#8-개인-리팩토링-평가와-촬영)를 따릅니다.

개인 기여 설명 → 질문 입력·진행 표시 → 답변·인용 원문 → 정보 부족 안내 → PDF → 개선 수치와 한계 순서로 시연합니다. 실제 촬영 전 대표 질문을 리허설하고 생성 성공·대체 답변을 구분합니다. 이번 작업에서 시연 영상 파일을 새로 녹화하지는 않았습니다.

팀 프로젝트 기여와 개인 확장 기여는 [README](../README.md)에 구분했습니다. 평가 원본은 `output/portfolio/`에 보관했습니다.
