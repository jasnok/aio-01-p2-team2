# 안전한 발췌가 있는 근거 후보 선택

기존 컨텍스트 생성은 문서 한도까지 우선 선택한 후 문장 단위 발췌를 만들었다. 상위 문서가 예산보다 긴 분리 불가능 문장만 갖고 있으면 제외되었지만 뒤의 사용 가능한 문서를 선택하지 않았다.

문서 선택 과정에서 안전한 발췌가 있는지 확인하고 그러한 문서만 한도에 포함한다. 출처 종류별 첫 안전 후보를 선택한 뒤 점수 순서로 남은 자리를 채운다. 동점 순서는 입력 순서이며 기존 문장·주변 예외 보존 규칙과 문서/발췌 예산은 유지한다. 후보별 발췌는 한 요청에서 한 번만 계산한다.

`backend/tests/test_evidence_context.py`에서 네 자료 종류의 상위 불가 문서 다음 후보 선택과 혼합 자료의 다양성 문제를 기존 코드의 5개 실패로 재현했다. 원문 offset·문서 수·발췌 예산·결정적 순서 및 모든 후보가 불가한 경우의 빈 컨텍스트를 확인한다. 기존 인용 ID 해결·답변 연결·검증 실패 대체 답변 테스트도 유지한다.

컨텍스트 가용성 개선이며 검색 관련성이나 법률 정확도의 수치 개선을 측정한 것은 아니다. 검색 결과·점수와 원문을 바꾸거나 긴 문장을 잘라 넣지 않는다. 새 모델 호출과 토큰 예산 확대는 없다. 불가 후보 뒤를 확인하므로 일부 입력은 발췌 검사 횟수가 증가할 수 있다.
