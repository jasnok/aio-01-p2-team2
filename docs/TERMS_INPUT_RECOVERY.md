# 법률 용어 대화 입력의 성공·실패 처리

법률 용어 대화가 성공한 뒤에도 질문이 남아 버튼 재클릭으로 동일 질문을 호출할 수 있었다. 성공 응답을 메시지와 대화 ID에 반영한 뒤 다음 화면 실행에서 입력만 비운다. 위젯 생성 전에 초기화해 Streamlit의 위젯 상태 변경 제약을 지킨다.

실패 시 입력·기존 메시지·대화 ID는 그대로 유지한다. 자동 재시도나 모델 중복 호출 방지용 서버 멱등성을 추가한 것은 아니며, 응답을 확인하지 못한 요청은 실제로 처리되었을 수도 있다. 실패 후 다시 누르는 동작은 사용자의 명시적 재시도다.

`frontend/tests/test_terms_context.py`의 실제 AppTest는 실패 입력 보존, 동일 내용의 명시적 재시도, 성공 후 빈 입력, 메시지·대화 ID 유지, 빈 재제출 시 추가 호출 없음을 확인한다. 기존 저장 후 후속 질문 연속성과 새 대화 초기화 테스트도 유지한다. 모델 요청 대신 결정적 테스트 응답을 사용했다.
