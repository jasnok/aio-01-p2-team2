# 리랭킹 후보 입력의 완전성

리랭킹 실험은 후보 ID·제목·본문 배열을 같은 길이로 검증한 뒤 묶는다. zip이 짧은 배열에 맞춰 후보를 조용히 버리는 경로를 차단했다. 제목과 본문은 공백이 아닌 문자열이어야 하며 문서 ID는 기존 자료에 사용하는 양의 정수 또는 공백이 아닌 문자열이다. 불리언·0·잘못된 본문·빈 전체 후보 집합은 모델 초기화 전에 실패한다.

같은 문서 ID와 본문 해시의 후보는 동일한 경우 한 번만 유지한다. 제목 등 후보 정보가 충돌하면 모호한 실험 입력으로 실패한다. 정상 pooled 후보의 ID·순서·결과 형식은 유지한다. 개별 변형의 후보가 비어 있어도 다른 변형의 후보가 있으면 비교할 수 있다.

새 회귀 테스트 11개와 기존 실험 출력 보존 테스트를 포함한 16개가 통과했다. 기존 자연어 질문 15개의 후보 집합이 그대로 보존되는지 모델 호출 없이 확인했다. 법률적 관련성이나 리랭킹 품질을 평가한 결과는 아니며 기존 원본 파일과 운영 검색 순위는 변경하지 않았다.
