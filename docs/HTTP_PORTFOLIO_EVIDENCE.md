# 발표 패널의 HTTP 측정 근거

발표 패널의 `HTTP 연결 재사용` 선택지는 기존 [측정 원본](../output/portfolio/frontend-http-pool.json)을 읽어 만든 숫자 요약을 표시한다. 새 API 요청이나 모델 호출은 하지 않는다.

생성 스크립트는 표본 수와 중앙값을 대조하고, 준비·측정 합계에 해당하는 동등 비교 쌍, 응답 SHA-256 형식, 인증·모델 요청 0회 및 측정 코드 출처를 검증한다. 질문·카탈로그 본문·키·토큰은 숫자 요약에 포함하지 않는다. 원본 내용 해시를 기존 방식으로 기록한다.

화면은 로컬 공개 카탈로그 GET과 기존 경로의 클라이언트 생성·종료 포함 범위를 명시한다. 전체 상담 속도나 법률 품질 수치로 해석하지 않는다. 측정 당시 작업 트리 변경과 코드 해시도 다운로드 요약에 보존한다. 자세한 측정은 [HTTP 연결 재사용 문서](FRONTEND_HTTP_POOL.md)를 참고한다.

`frontend/tests/test_portfolio_evidence.py`는 화면 선택·세 분야 표·안내와 원본 불일치 거절을 검증한다. 표본·중앙값·동등성·범위·해시의 다섯 손상 사례를 검사하며 기존 줄바꿈 독립 해시·개인정보 비포함·파일 누락 안내를 유지한다. 원본의 동등성 카운트를 검증하는 것이며 실제 API 비교를 재실행하는 검사와는 구분한다.
