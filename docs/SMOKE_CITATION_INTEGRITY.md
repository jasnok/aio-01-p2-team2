# 시연 스크립트의 인용 무결성 검증

`portfolio_smoke.py`는 LLM 결과의 모든 주장에 공백이 아닌 본문과 최소 하나의 인용이 있는지 확인한다. 인용의 근거 ID와 인용문은 공백이 아닌 문자열이어야 하며, 지정된 원문에 인용문이 그대로 존재해야 한다. 같은 근거 ID에 서로 다른 원문이 있으면 모호한 결과로 실패 처리한다.

잘못된 주장·인용 구조는 citation_integrity=False로 남겨 측정 집계에서 성공으로 포함되지 않게 한다. spans 모드의 답변 일치 검사도 인용 구조 검증이 성공한 경우에만 통과한다.

## 검증 범위

모의 HTTP·SSE 응답으로 실제 run_scenario 경로와 성공 집계까지 검증했다. 초기 새 테스트 13개 중 수정 전 9개가 실패했다. 이후 잘못된 원문 구조·일부 주장만 유효한 경우·동일 원문 중복 사례 7개를 추가했으며, 수정 후 기존 지연·집계 테스트를 포함한 50개가 통과했다. 실제 유료 모델 호출이나 기존 측정 파일 갱신은 하지 않았다.

이 검사는 인용의 구조와 원문 일치에 관한 것이다. 법률적 정답·최신성이나 주장 전체가 인용으로 뒷받침되는지에 대한 의미 검증을 대신하지 않는다.
