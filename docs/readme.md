# LawPath

**생활 속 법률 문제를 입력하면 관련 자료와 쉬운 설명을 찾아주는 서비스입니다.**

“계약이 끝났는데 보증금을 돌려받지 못했어요.”

“퇴직했는데 퇴직금을 받지 못했어요.”

어떤 법을 찾아야 할지 몰라도 자신의 상황을 평소 사용하는 말로 입력할 수 있습니다. LawPath는 관련 법령·판례·상담사례를 검색하고, 내용을 이해하기 쉽게 정리해 출처와 함께 보여줍니다.

## 어떤 문제를 물어볼 수 있나요?

| 분야 | 질문 예시 |
|---|---|
| 임대차·주거 | 계약이 끝났는데 집주인이 보증금을 돌려주지 않습니다. 어떤 법 조문을 확인해야 하나요? |
| 근로·임금 | 퇴직했는데 회사가 퇴직금을 지급하지 않습니다. 지급 기한과 관련 법을 알려주세요. |
| 소비자·중고거래 | 주문한 물건이 배송되지 않았습니다. 환불을 요청하려면 어떤 내용을 확인해야 하나요? |

## 어떻게 사용하나요?

1. **분야를 선택합니다.** 자신의 상황에 맞는 분야를 고릅니다.
2. **상황과 궁금한 점을 입력합니다.** 언제, 누구와, 어떤 일이 있었는지 적으면 도움이 됩니다. 상대방에게 요청한 내용이나 보관 중인 자료가 있다면 함께 적어주세요.
3. **분석을 시작합니다.** 질문을 이해하기 어려우면 필요한 정보를 추가로 물어봅니다. 일반적인 법률 안내 질문에는 날짜나 증거를 모두 입력할 필요가 없습니다.
4. **답변과 근거를 확인합니다.** 상황 요약, 설명, 관련 자료와 출처를 확인합니다. 어려운 법률 용어는 다시 질문할 수 있습니다.

입력 확인 항목의 **‘해당 없음’은 정보가 부족하다는 뜻이 아닙니다.** 해당 질문을 검색하는 데 꼭 필요하지 않은 항목이라는 의미입니다.

## 주요 기능

| 기능 | 할 수 있는 일 |
|---|---|
| 내 사례 분석 | 자신의 상황에 관련된 법률 자료와 설명 확인 |
| 상황 요약 | 입력한 문제와 핵심 쟁점을 간단하게 확인 |
| 근거 확인 | 법령·판례·상담사례의 내용과 출처 확인 |
| 법률 용어 대화 | 어려운 용어와 제도를 쉬운 말로 질문 |
| 분석 결과 PDF | 분석 내용을 문서로 내려받기 |
| 저장·질의 이력 | 회원이 선택해서 저장한 분석과 대화 다시 보기 |
| FAQ·질문 게시판 | 자주 하는 질문 확인, 질문과 댓글 작성 |
| 알림 | 질문·댓글 등록 등의 처리 결과 확인 |

법령은 법과 조문, 판례는 법원의 판단 사례, 상담사례는 소비자원 등에서 제공하는 상담·해석 자료입니다. 서로 다른 종류의 자료이므로 결과에서도 구분해 표시합니다.

## 회원가입이 꼭 필요한가요?

비회원도 사례 분석과 법률 용어 대화를 이용할 수 있습니다. 회원은 필요한 분석과 대화를 선택해 저장하고, 자신의 이력에서 다시 확인할 수 있습니다.

비회원 이력은 임시 보관 대상이며 실제 보관 기간은 서버 설정에 따라 달라집니다. 계속 보관할 자료는 분석 결과 PDF 등으로 따로 보관할 수 있습니다. 회원가입 시 기존 비회원 이력이 자동으로 이전되는 것은 아닙니다.

질문 게시판에서는 공개글과 비밀글을 선택할 수 있습니다. 비밀글도 제목은 목록에 보이므로 제목에 개인정보를 적지 마세요. 비밀글의 본문과 댓글은 작성자와 관리자에게 접근을 제한합니다.

## 답변은 어떻게 만들어지나요?

```text
질문 입력 → 검색 가능 여부 확인 → 관련 자료 검색 → AI가 설명 정리 → 결과와 출처 표시
```

Backend가 질문을 확인한 뒤, MCP 서버의 검색 도구를 통해 DB에 저장된 법률 자료를 찾습니다. LLM은 검색된 근거를 바탕으로 답변을 정리합니다. 처리 중에는 화면에서 진행 상태를 확인할 수 있습니다.

분야별로 정해진 검색 도구를 사용하며, 실제로 찾은 자료만 표시합니다. 검색 결과가 항상 같은 개수로 나오지는 않습니다. 법률 용어 대화는 별도의 AI 설명 기능으로, 매번 새로운 자료 검색을 수행하는 것은 아닙니다.

## 이용할 때 알아두세요

- LawPath는 법률 정보 탐색을 돕는 서비스입니다. 법률 자문이나 승소 가능성을 보장하지 않습니다.
- 비슷한 판례가 있어도 사실관계에 따라 적용이 달라질 수 있습니다. AI 설명에는 오류가 있을 수 있으므로 출처·원문을 함께 확인하세요.
- 내려받는 PDF는 LawPath의 분석 보고서이며, 법원이 발급한 판결문 원본은 아닙니다.
- 주민등록번호, 계좌 비밀번호 등 민감한 정보는 입력하지 마세요.

## 프로젝트 구성

| 구성 | 역할 |
|---|---|
| Frontend · Streamlit | 질문 입력과 결과 화면 |
| Backend · FastAPI | API, 사용자 확인, 분석과 저장 처리 |
| Agent·LLM | 입력 판단, 검색 실행 흐름, 답변 정리 |
| MCP | 법률 검색 도구 제공 |
| PostgreSQL·pgvector | 자료 저장과 의미 기반 검색 |
| Redis | 설정에 따라 세션과 비회원 임시 이력 보관 |

현재는 MVP 단계입니다. 회원 인증과 선택한 대화의 DB 저장 경로가 구현되어 있지만, 질문 게시판·댓글·알림 및 Agent 실행 상태에는 메모리 저장 방식이 남아 있습니다. 따라서 모든 데이터가 서버 재시작 후에도 유지되는 것은 아닙니다.

개발 및 실행 방법은 [저장소 README](../README.md)를 참고하세요.
