## 3. 공개글

- [ ] 비회원으로 공개글을 작성하면 별도 잠금 해제 없이 본문이 보인다.
- [ ] 다른 비회원·회원·관리자 역할에서도 공개글 본문과 댓글이 보인다.
- [ ] 모든 역할에서 공개글 댓글을 작성할 수 있다.
- [ ] 공개글 본문 검색어로 게시글을 찾을 수 있다.

## 4. 비밀글

- [ ] 작성자가 아닌 비회원·회원에게는 제목과 잠금 안내만 보인다.
- [ ] 작성자는 게시글 비밀번호가 틀리면 본문을 볼 수 없다.
- [ ] 작성자는 올바른 비밀번호로 잠금을 해제하면 본문과 댓글을 볼 수 있다.
- [ ] 관리자는 비밀글 본문과 댓글을 볼 수 있고 댓글을 작성할 수 있다.
- [ ] 비밀글 본문에만 있는 검색어로는 게시글을 찾을 수 없다.
- [ ] 비밀글 제목 검색어로는 게시글을 찾을 수 있다.

## 5. 댓글 CRUD와 권한

- [ ] 비회원 댓글 작성 시 4~20자 댓글 비밀번호가 필요하다.
- [ ] 비회원은 올바른 댓글 비밀번호로 본인 댓글을 수정·삭제할 수 있다.
- [ ] 틀린 비밀번호 또는 다른 비회원 Session으로 댓글을 수정·삭제할 수 없다.
- [ ] 회원은 본인 댓글만 수정·삭제할 수 있다.
- [ ] 관리자는 운영 목적으로 댓글을 삭제할 수 있다.
- [ ] 댓글 등록 후 알림이 생성된다.
- [ ] 비밀글 알림에 질문 본문이나 댓글 원문이 노출되지 않는다.
- [ ] 사용자 댓글은 공식 법률 답변이 아니라는 안내가 보인다.
