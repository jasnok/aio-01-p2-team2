# Frontend 작업 브랜치

- 프론트엔드 작업을 시작하기 전에 현재 브랜치와 작업 트리 상태를 확인한다.
- 프론트엔드 변경과 커밋은 `frontend` 브랜치에서 수행한다. `develop`에 직접 커밋하지 않는다.
- 기존 사용자 변경사항을 보존한다. 안전하게 브랜치를 전환할 수 없으면 사용자에게 상황을 알린다.
- 푸시 및 `develop` 대상 Issue/PR 생성·병합은 사용자의 요청이 있을 때 수행한다.
- 커밋에는 해당 작업 파일만 포함하고 개인 메모, 로그, 비밀정보는 포함하지 않는다.
- 병합 후에도 로컬 작업 브랜치는 `frontend`로 유지한다.
